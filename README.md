# DS Assignment 2 - Question 6

## Graph Representation

This assignment implements graph representation using:

- Adjacency Matrix
- Adjacency List
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Vertex Search

The program uses a graph with 6 vertices (A, B, C, D, E, F) and demonstrates the above operations.
